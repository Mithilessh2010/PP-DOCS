---
title: Creating a Pose
---

Now that the follower is set up, we need to tell it where the robot starts and where we want it to go.

If you need help setting up the follower, go back to [Creating a Follower](./creating-a-follower).

Positions are represented using a `Pose`. A Pose contains an x-coordinate, y-coordinate, and heading.

### Creating a PoseFactory

First, add the imports for `PoseFactory` and `Pose`:

```java
import com.pedropathing.api.PoseFactory;
import com.pedropathing.math.Pose;
```

We'll use a `PoseFactory` to create the Poses for our autonomous.

For this guide, we'll use degrees for heading values:

```java
private final PoseFactory p = PoseFactory.degrees();
```

You can use `PoseFactory.radians()` instead if you prefer to enter headings in radians.

### Creating the Starting Pose

Use `p.of()` to create a Pose for where the robot starts:

```java
private final Pose startPose = p.of(24, 24, 0);
```

The values are given in the order:

```java
p.of(x, y, heading);
```

Our `startPose` is at `(24, 24)` with a heading of `0` degrees.

### Creating the End Pose

Next, create another Pose for where we want the robot to go:

```java
private final Pose endPose = p.of(48, 48, 90);
```

Our `endPose` is at `(48, 48)` with a heading of `90` degrees.

Your Poses should now look like this:

```java
private final PoseFactory p = PoseFactory.degrees();

private final Pose startPose = p.of(24, 24, 0);
private final Pose endPose = p.of(48, 48, 90);
```

### Setting the Starting Pose

The follower's localizer also needs to know where the robot starts.

After creating the follower, set its Pose to `startPose`:

```java
follower = Constants.create(hardwareMap);
follower.setPose(startPose);
```

<Callout title="Tip" type="info">
    See the [Coordinates](/docs/pathing/reference/coordinates) page for more information about the field coordinate system and heading directions.
</Callout>

### Next Step

We now have a starting Pose and an ending Pose:

```java
private final Pose startPose = p.of(24, 24, 0);
private final Pose endPose = p.of(48, 48, 90);
```

We'll use these same Poses in the next guide to create a path between them.

Continue to [Creating a Path](./path-creation).
