## Setup

in `Constants.java` inside the `Constants` class, add an instance of `MecanumConfig`.
Make sure to replace the motor names with your actualy names.

```java title="Constants.java"
public static MecanumConfig mecanumConfig = new MecanumConfig(
            c -> {
                c.frontLeftName.set("lf");
                c.backLeftName.set("lb");
                c.frontRightName.set("rf");
                c.backRightName.set("rb");

                c.frontLeftDirection.set(DcMotorSimple.Direction.REVERSE);
                c.backLeftDirection.set(DcMotorSimple.Direction.REVERSE);
                c.frontRightDirection.set(DcMotorSimple.Direction.FORWARD);
                c.backRightDirection.set(DcMotorSimple.Direction.FORWARD);

                c.manualBrakeMode.set(true);
            }
    );
```
<Callout title="Important" type="warning">
    Make sure that your motor names and directions are correct. If this is configured incorrectly, the remaining tuners will not work as expected.
        - The motor names should correspond to the names given to the motors in the Driver Station configuration.
        - When positive power is applied to all four motors, the drivetrain should move forward. It's likely that you will have to reverse either the left or right side motors!
</Callout>
Then, add `new Mecanum` to `create`:

```java title="Constants.java"
return new Follower(
    // Localizer Config
    new Mecanum(h, driveConfig)
    // Foresight Config
    );
```
