<Callout title="Prerequisites" type="info">
  Ensure that two odometry pods are connected: one that is parallel to the length
  of your chassis (forward) and another that is perpendicular to your chassis length (lateral).
</Callout>

<Callout title="Common Mistakes" type="warning">
  * Make sure the pinpoint is plugged into an I2C port **other than port 0**. This is because the Control Hub's built in IMU uses port 0.
  * Make sure the pinpoint has the sticker side (with the ports) facing up.
  * Make sure the forward pod is plugged into the x port on the pinpoint and the strafe pod is plugged into the y port.
</Callout>

## Setup

In `Constants.java` inside the `Constants` class, add an instance of `PinpointConfig`. Make sure to replace the pinpoint name with the actual HardwareMap name of your Pinpoint.

```java title="Constants.java"
public static PinpointConfig localizerConfig = new PinpointConfig(
    c -> {
        c.name.set("pinpoint");
        c.xPodOffset.set(-0.7);
        c.yPodOffset.set(-0.3);
        c.xPodDirection.set(GoBildaPinpointDriver.EncoderDirection.REVERSED);
        c.yPodDirection.set(GoBildaPinpointDriver.EncoderDirection.REVERSED);
    }
);
```

The offsets and encoder directions above are examples. These values will depend on your robot.

Then, add `PinpointLocalizer` to `create`:

```java title="Constants.java"
public static Follower create(HardwareMap h) {
    return new Follower(
        new PinpointLocalizer(h, localizerConfig),
        // Drivetrain Config
        // Foresight Config
    );
}
```

## Offsets

Offsets can be found **manually** or **automatically**.

### Automatic Offset Tuning

The Pinpoint AutoTuner can automatically determine your pod directions and pod offsets.

### Add the Tuner

Inside your `Tuning` class, add:

```java title="Tuning.java"
@Tuner
public static Procedure pinpointTuner() {
    return new PinpointTuner();
}
```

Build and send the updated code to the Robot Controller.

### Open AutoTune

While connected to the Robot Controller, open the following address in your browser:

```text
http://192.168.43.1:10158
```

Select **Pinpoint Procedure**.

### Pinpoint Setup

Enter the **HardwareMap name** of your Pinpoint and select the odometry pod type installed on your robot.

For example, if your `Constants.java` contains:

```java title="Constants.java"
c.name.set("pinpoint");
```

then enter:

```text
pinpoint
```

in the **HardwareMap Name** field.

Next, select the odometry pod type that matches the pods installed on your robot, then press **Submit**.

### Forward Direction Identification

Press **Continue**, then push the robot straight **forward**.

After moving the robot forward, stop the OpMode.

The tuner will determine whether the **x pod**, which is the forward pod, should be set to `FORWARD` or `REVERSED`.

Set `xPodDirection` in your `PinpointConfig` to the value determined by the tuner:

```java title="Constants.java"
c.xPodDirection.set(GoBildaPinpointDriver.EncoderDirection.FORWARD);
```

or:

```java title="Constants.java"
c.xPodDirection.set(GoBildaPinpointDriver.EncoderDirection.REVERSED);
```

### Strafe Direction Identification

Press **Continue**, then push the robot to the **left**.

After moving the robot to the left, stop the OpMode.

The tuner will determine whether the **y pod**, which is the strafe pod, should be set to `FORWARD` or `REVERSED`.

Set `yPodDirection` in your `PinpointConfig` to the value determined by the tuner:

```java title="Constants.java"
c.yPodDirection.set(GoBildaPinpointDriver.EncoderDirection.FORWARD);
```

or:

```java title="Constants.java"
c.yPodDirection.set(GoBildaPinpointDriver.EncoderDirection.REVERSED);
```

<Callout title="Important" type="warning">
  During the Strafe Direction Identification step, push the robot to the **left**.
</Callout>

### Offsets Identification

Press **Continue**, then rotate the robot in place approximately **180 degrees**.

After the robot has completed the rotation, stop the OpMode.

The tuner will automatically calculate the x and y pod offsets.

### Applying the Results

Once the tuner is complete, open the **Java** tab.

AutoTune will generate a `PinpointConfig` using the values determined during the tuning procedure.

Copy the generated configuration into the `PinpointConfig` in your `Constants.java` file.

The generated configuration includes:

- HardwareMap name
- Pod type
- X pod direction
- Y pod direction
- X pod offset
- Y pod offset

<Callout title="Note" type="info">
  Use the values generated by the tuner for your robot instead of the example values shown on this page.
</Callout>

## Encoder Resolution

The odometry pod type can be configured in `PinpointConfig`.

For example, for the goBILDA 4 Bar Pod:

```java title="Constants.java"
c.podType.set(
    GoBildaPinpointDriver.GoBildaOdometryPods.goBILDA_4_BAR_POD
);
```

The automatic tuner will also ask you to select the odometry pod type being used on your robot.

## Encoder Directions

The Pinpoint AutoTuner can determine both encoder directions automatically.

The forward pod is connected to the Pinpoint's x port and is configured using `xPodDirection`.

```java title="Constants.java"
c.xPodDirection.set(GoBildaPinpointDriver.EncoderDirection.FORWARD);
```

or:

```java title="Constants.java"
c.xPodDirection.set(GoBildaPinpointDriver.EncoderDirection.REVERSED);
```

The strafe pod is connected to the Pinpoint's y port and is configured using `yPodDirection`.

```java title="Constants.java"
c.yPodDirection.set(GoBildaPinpointDriver.EncoderDirection.FORWARD);
```

or:

```java title="Constants.java"
c.yPodDirection.set(GoBildaPinpointDriver.EncoderDirection.REVERSED);
```

You can also verify the encoder directions manually using the localization test under the localization folder in the tuning OpMode.

Move the robot forward. The x coordinate should increase.

Next, move the robot left. The y coordinate should increase.

If the x coordinate changes in the wrong direction, switch `xPodDirection` between `FORWARD` and `REVERSED`.

If the y coordinate changes in the wrong direction, switch `yPodDirection` between `FORWARD` and `REVERSED`.
