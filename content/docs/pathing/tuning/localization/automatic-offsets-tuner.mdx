---
title: Automatic Offsets Tuner
---

### Prerequisites
This tuner is made to automatically find odometry offsets for [Two Wheel](https://pedropathing.com/docs/pathing/tuning/localization/two-wheel) and [Pinpoint](https://pedropathing.com/docs/pathing/tuning/localization/pinpoint) localizers.  
Currently, it only supports two deadwheels in the calculations.  

### Steps
* Place the robot on the field or a few tiles where it has enough space to spin in place
* Select and run the tuner `Automatic Offsets Tuner`.
* The robot will spin in place for a few seconds
* After the tuner is done, read the `forwardY` and set that to your `xPodOffset`
* Then read the `strafeX` value and set that to your `yPodOffset`
